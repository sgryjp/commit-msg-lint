# 表示カラムによる行長の測定

[English](0001-display-column-measurement.md)

行長はバイト数や書記素クラスタ数ではなく、`unicode-width` クレートの文字列幅アルゴリズムを使い、
表示カラム数で測定する。日本語の文字などの幅広文字は 2 カラムと数える。
幅が曖昧な文字は既定では 1 カラムと数えるが、2 カラムと数えるよう設定できる。
書記素クラスタ数は利用者が認識する文字数をよりよく反映するが、`a` と `あ` を同じ長さに数えるため、
コミットログの表示幅制限には適さない。

端末やフォントの描画に完全に一致させることはできないため、リリースごとにクレートと Unicode データの
バージョンを固定し、更新があれば文書化する。
