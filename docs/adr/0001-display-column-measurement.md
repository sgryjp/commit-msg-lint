# Display Column による行長測定

行長はバイト数や書記素クラスタ数ではなく、`unicode-width` crate の文字列幅アルゴリズムによる Display Column で測定する。日本語などの wide 文字は 2 列として扱い、`ambiguous-width` は既定で 1 列、設定で 2 列に変更できる。書記素クラスタ数は利用者が認識する文字数には適するが、`a` と `あ` を同じ長さにするため、コミットログの表示幅制約には適さない。端末・フォントによる完全な一致は保証できないので、crate と Unicode データの版を各リリースで固定し、更新を明示する。
