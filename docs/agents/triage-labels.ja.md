# トリアージラベル

[English](triage-labels.md)

スキルは標準となる 5 つのトリアージ上の役割を使う。このファイルは、それらの役割を
このリポジトリの issue トラッカーで実際に使用するラベル文字列に対応付ける。

| mattpocock/skills のラベル | このトラッカーのラベル | 意味                                 |
| -------------------------- | ---------------------- | ------------------------------------ |
| `needs-triage`             | `needs-triage`         | メンテナーによる issue の評価が必要 |
| `needs-info`               | `needs-info`           | 報告者からの追加情報を待っている    |
| `ready-for-agent`          | `ready-for-agent`      | 仕様が完成し、AFK エージェントに委任可能 |
| `ready-for-human`          | `ready-for-human`      | 人間による実装が必要                 |
| `wontfix`                  | `wontfix`              | 対応しない                           |

スキルが役割に言及した場合（例:「AFK 対応可能のトリアージラベルを付ける」）は、
この表の対応するラベル文字列を使う。

実際に使用する語彙に合わせて「このトラッカーのラベル」列を編集する。
